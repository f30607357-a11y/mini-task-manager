# Mini Task Manager

A simple React application built with Vite to demonstrate core React concepts.

## Features

- Add a new task
- Delete a task
- Toggle task completion
- Fetch tasks from an API using `useEffect`
- React Router navigation
- Light/Dark theme using Context API

## Technologies Used

- React
- Vite
- React Router
- JavaScript (ES6+)

## Installation

Clone the repository:

```bash
git clone https://github.com/<your-github-username>/mini-task-manager.git
```

Go to the project directory:

```bash
cd mini-task-manager
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
